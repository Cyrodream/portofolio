# Portfolio Fairuz Azzahran

Website portofolio responsif menggunakan HTML, CSS, dan JavaScript murni.

## Cara menjalankan
1. Ekstrak folder/ZIP.
2. Buka `index.html` di browser.
3. Untuk pengalaman pengembangan yang lebih nyaman, buka folder ini di VS Code dan gunakan ekstensi Live Server.

## Fitur
- Desain modern dan responsif untuk HP maupun desktop
- Mode gelap/terang yang tersimpan di browser
- Efek teks mengetik
- Animasi saat bagian halaman muncul
- Filter proyek berdasarkan kategori
- Modal detail proyek
- Indikator progres scroll dan tombol kembali ke atas
- Menu navigasi mobile
- Tahun footer otomatis

## Personalisasi sebelum dipublikasikan
- Ganti `emailkamu@example.com` di `index.html` dengan email aktif.
- Ganti tautan GitHub/LinkedIn dengan profil asli milikmu.
- Ganti contoh proyek dengan proyek yang benar-benar kamu buat.
- Sesuaikan level skill dengan kemampuanmu saat ini.
- Tambahkan tautan demo dan repositori pada setiap proyek.

Tidak memakai framework. Font Google Fonts membutuhkan koneksi internet; jika offline, website akan memakai font cadangan.
